# site-block-extension

Tired of using website blockers that limit the pages that you can block? Well I am too that's why I was inspired to redo this Medium article.


# How to use this super minimal site blocker:
1. Enter Developer Mode from your browser settings.
2. Assuming that you've already cloned this repository, click "Load Unpacked" button and click on the root folder.
3. Load it and update `rules.json` based on sites that you're planning to block.
